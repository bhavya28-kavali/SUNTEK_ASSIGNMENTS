# Week 1 - JavaScript Basics

## 📌 Project Overview
This repository contains JavaScript programs created during Week 1 practice.

The programs cover:
- Operators
- Control Statements
- Array Operations

---

## 📚 Topics Covered

### 🔹 Operators
Programs using:
- Arithmetic Operators
- Assignment Operators
- Comparison Operators
- Logical Operators

### 🔹 Control Statements
Programs using:
- if statement
- if-else statement
- nested if
- switch statement
- loops
  - for loop
  - while loop
  - do-while loop

### 🔹 Array Operations
Programs using:
- push()
- pop()
- shift()
- unshift()
- map()
- filter()
- sort()
- reverse()

## ▶️ How to Run

1. Open terminal
2. Navigate to project folder

```bash
cd Week-1
```

3. Run JavaScript files using Node.js

```bash
node operators.js
node controlStatements.js
node arrayOperations.js
```
