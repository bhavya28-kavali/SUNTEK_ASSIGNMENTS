# Week 3 - Product Backend Development

## 📌 Project Overview
This project contains the backend implementation for product management using JavaScript and Node.js.

The backend performs:
- Product data handling
- API creation
- CRUD operations
- Server-side functionality

---

## 📚 Features Implemented

### 🔹 Product Management
- Add products
- View products
- Update product details
- Delete products

### 🔹 Backend Development
Implemented backend using:
- Node.js
- Express.js

### 🔹 CRUD Operations
Performed:
- Create
- Read
- Update
- Delete

### 🔹 API Handling
Created REST APIs for:
- Product listing
- Product updates
- Product deletion
- Product creation

---

## 🛠 Technologies Used
- JavaScript
- Node.js
- Express.js
- Postman (for API testing)

## ▶️ How to Run

1. Open terminal
2. Navigate to project folder

```bash
cd Week-3-main
```

3. Install dependencies

```bash
npm install
```

4. Start the server

```bash
node server.js
```

or

```bash
npm start
```

---

## 🚀 API Functionalities

- GET → Fetch products
- POST → Add new product
- PUT → Update product
- DELETE → Remove product
